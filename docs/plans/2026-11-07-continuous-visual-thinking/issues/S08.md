# [P1][S08] 将真实语音接入持续理解模式，隔离旧逐句出页链路

状态：待开发。所属方案：持续理解与动态思维可视化 v1。

## 目标

在同一项目中通过 ?mode=semantic 实际边说边形成关系图；partial 能更新理解，final 不强制换页。

## 前置任务

S02、S05、S07

## 开发入口

public/stage.js 的最小输入适配、public/semantic/app.js、public/index.html 与必要 server/check 配置。

先读 [开发交接](../HANDOFF.md)、[协议](../protocol.md)、[架构](../architecture.md) 与 [验收](../acceptance.md)。

## 工作范围

- 采集创建段时绑定语义 segment/order，ASR 请求发出前捕获 revision/epoch，partial/final 回来先送账本。
- 复用现有麦克风、VAD、ASR、打字和文件输入；不复制第二套音频采集。
- semantic 模式不执行旧 provisional 原话大标题、旧 decide 逐句造页和 speculate 预测上屏；字幕与理解画面分别更新。
- 旧默认模式保留原行为与最近修复；模式切换、重置、停止输入的收尾行为明确，旧请求不能串入新会话。
- 加增量文本回放入口方便无模型音频环境复现；诊断显示正在听/理解延迟/降级，不能制造已测0ms幻觉。

## 验收

- [ ] 真实麦克风在没有明显停顿时，partial 已触发语义请求及有效图变化；相邻音频段可继续同一场景。
- [ ] A final 延迟、B partial 先到时，输入顺序和来源正确；C02 ASR 改写能修正图。
- [ ] 旧打字/演示/麦克风/文件入口进行必要回归；无 Key 时字幕仍能工作且不声称理解关系。
- [ ] 运行与本改动相关的检查，并完成 `npm run check`、`npm test`；报告真实执行结果与仍未验证项。

对应验收场景：C01—C03、C09—C11；真实语音质量留给 S10。

## 本项不包含

不默认切换到新模式，不更换 ASR，也不把模拟回放称为真实语音验收。

## 交付

一个聚焦 PR，链接本 Issue，说明输入输出、行为变化、验证证据和剩余限制。依赖未完成或验收缺失时保留 Issue 打开。模型无 Key 降级、接口连通与 mock 不能作为真实语义验收。
