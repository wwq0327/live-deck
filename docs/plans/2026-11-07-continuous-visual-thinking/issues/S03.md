## 工作范围

- 把 acceptance.md 的 C01—C14 整理为带时间、revision、来源、检查点、必需/禁止关系的 fixture。
- 回放器每次只向输入适配器释放当前已到达事件；模型请求不得接触未来事件、答案或期望图。
- 建立受控导演替身，支持延迟、逆序、失败、非法操作与持续负载，真实语义质量不由替身判定。
- 输出可复查的 input/request/commit 事件轨迹，分开记录讲话时间与墙钟耗时。
- 支持手动逐步、真实节奏和确定性快速回放；加速回放不得被当作真实端到端延迟。

## 验收

- [ ] C01 partial 期间可产生理解任务；C03/C07 修改过去关系；C09 重置后旧结果不能上屏。
- [ ] C10 慢响应持续输入可稳定复现，final 信息未消费情况可统计。
- [ ] 检查模型收到的请求快照，确认不存在未来文字或检查点答案；fixture 的文字示例明确标为模拟数据。
- [ ] 运行与本改动相关的检查，并完成 `npm run check`、`npm test`；报告真实执行结果与仍未验证项。

对应验收场景：C01—C14。

## 本项不包含

不使用真实付费 API 作为 CI 前提，不把 mocked 关系当真实 Flash 能力。

## 交付

一个聚焦 PR，链接本 Issue，说明输入输出、行为变化、验证证据和剩余限制。依赖未完成或验收缺失时保留 Issue 打开。模型无 Key 降级、接口连通与 mock 不能作为真实语义验收。
