# [方案总任务] 持续理解讲话并以动态图示呈现可修正的思维关系

GitHub：[#21](https://github.com/wwq0327/live-deck/issues/21)

状态：方案已保存，功能待开发。用户授权本轮制定方向和提交 Issues，应用代码由用户使用 DeepSeek Flash 实施。

## 要解决的问题

当前用户测试反馈：系统主要把实时识别的文字拼成页面，没有充分表达跨句因果、对比、组成与转折；逐段处理不够连贯，后文也难以修正前面的理解。

目标是边听、边维护可修正的语义结构，再局部更新简单图形。动画服务于解释关系，图片作为辅助；不是增加模板数量或更快显示原话。

## 已确定的实施方向

保留 Node.js、本地 ASR 和原生 DOM/SVG。新模式通过 ?mode=semantic 进入，旧默认模式继续可用。Flash 作为语义导演候选，输出有证据的小批操作；对象与关系保持稳定身份，可以增加、更正、撤回、回看。partial 替换草稿，final 不静默丢失；单在途请求合并待输入，不逐句排队出页，也不持续取消到没有结果。

先完成四类场景：因果、对比、组成、汇聚。没有关系可画时允许中性文本。问题、设想、概数、否定、条件不能被包装成确定结果或错误因果。

## 总体验收

- 确定性协议/竞态测试通过，旧检查不回退。
- 真实 Flash 逐步回放能表达跨句关系、转折及回头修正；不能提前看到后文。
- 增量录屏证明稳定对象与局部动画，关系可阅读。
- 真实语音完成至少两段60—90秒以及一次5—10分钟连续使用，记录准确性、延迟、积压和tokens。
- 具体建议门槛以验收文档为准。缺真实模型、真实语音或人工视觉验收时，本总任务保持打开，不能用接口连通、预制演示或无 Key 规则代替。
