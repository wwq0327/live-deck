## 工作范围

- 先支持带可靠 speaker ID 的文本/音轨输入，保留每个人对观点的归属、赞同、反对和引用关系。
- 不能把乙反对甲画成甲修正自己，也不能把多人主张合并成已达成共识。
- speaker unknown 时明确未知，不猜身份；人工标记说话人与真实自动分离分开报告。
- 评估本地说话人分离或分轨录音的成本、延迟和准确性，再实施选定路径；需要云端音频时另行取得授权。

## 验收

- [ ] C15 带标记回放正确表现分歧，unknown 不发明姓名；原单讲者场景无退化。
- [ ] 若交付真实多人音频能力，必须有真实双人对话的归属/切换错误记录，不能仅靠文本标签关闭。
- [ ] 明确支持的录音条件与未验证情形，保持关系可修正和有来源。
- [ ] 运行与本改动相关的检查，并完成 `npm run check`、`npm test`；报告真实执行结果与仍未验证项。

对应验收场景：C15，并回归 C03/C09。
