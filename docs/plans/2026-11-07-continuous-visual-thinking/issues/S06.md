# [P1][S06] 建立按稳定对象 ID 更新的 DOM/SVG 渲染与局部动画

状态：待开发。所属方案：持续理解与动态思维可视化 v1。

## 目标

关系和文字可以原地增加、修正、撤回；已存在图形不因为新信息而全页重建。

## 前置任务

S01

## 开发入口

建议 public/semantic/renderer.js、基础样式、可独立运行的静态增量预览与浏览器检查。

先读 [开发交接](../HANDOFF.md)、[协议](../protocol.md)、[架构](../architecture.md) 与 [验收](../acceptance.md)。

## 工作范围

- Scene/Node/Edge ID 映射到稳定 DOM/SVG 元素；新增、属性修改、撤回分别更新，禁止整页 innerHTML 重写。
- 定义新增节点、连线建立、焦点变化、旧边撤回/替换的语义动画；文本修正只改对应标签。
- 模型标签用 textContent/安全属性，不执行 HTML；坐标与布局交给程序。
- 保留视图快照与最新语义状态的差异接口，供 S09 保持/恢复使用。
- 支持 reduced-motion、1600x900 和1280x720；稳定对象不重复播放入场，不以随机换底色制造变化。

## 验收

- [ ] C12 中仅修改一个标签/一条边后，未受影响 DOM 对象身份不变，节点位置稳定。
- [ ] 保存增量前后截图或录屏，并记录减少动态效果模式；无文本溢出或互相遮挡。
- [ ] 用脚本标记既有对象观察是否重建，不能只测生成的 HTML 字符串；安全字符串不变成可执行元素。
- [ ] 运行与本改动相关的检查，并完成 `npm run check`、`npm test`；报告真实执行结果与仍未验证项。

对应验收场景：C12、C14 的视图基础。
