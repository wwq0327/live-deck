## 工作范围

- 按协议接收 current graph、sources、recent scenes、unresolved，返回完整短 JSON ops/considered；不能只取最后一句。
- 用现有 DIRECTOR_MODEL（默认 deepseek-flash）及关闭思考起步；初始输出上限900 tokens、上游超时6s可配置，实际数值由 S10 评测。
- 提示词写清因果与先后、提问与断言、方案与成果、否定及回头修正；提供正例和禁止关系反例。
- 不预测未说出的结论，不生成 HTML 或坐标；不因每句有新信息强制换场景。
- 复用 Host/Origin/类型/体积校验，完整校验模型响应；客户端断开/超时可取消上游。
- 无 Key/超时/非法 JSON 显式 degraded，保留旧图，不复用会猜因果的本地规则；旧 /api/direct* 协议保持。
