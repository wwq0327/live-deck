# [P1][S07] 实现因果、对比、组成、汇聚四类关系场景与统一主题

状态：待开发。所属方案：持续理解与动态思维可视化 v1。

## 目标

使用简单、友好的图形解释讲话关系，形成可持续展开的模板，而不只是标题和列表换皮。

## 前置任务

S06

## 开发入口

建议 public/semantic/layouts.js、theme.css 与按关系操作驱动的预览用例。

先读 [开发交接](../HANDOFF.md)、[协议](../protocol.md)、[架构](../architecture.md) 与 [验收](../acceptance.md)。

## 工作范围

- 因果链有明确方向；对比围绕共同维度且不画因果箭头；组成使用包含/堆叠；汇聚将多个来源连接到目标。
- 提供 text 中性场景，顺序/条件等尚无专用图形时忠实表达，不强套因果。
- 绿色低对比底板、白色正文、绿色重点、简洁几何；独立设计资产，不把参考视频截图作为产品素材。
- 3—6节点/最多8边为初始可见容量；超出时发出续接需求并保留语义信息，不能静默 slice。
- 场景内布局稳定，焦点随解释变化；设想/提问/暂定关系有清楚的样式或文字提示。

## 验收

- [ ] 四类场景分别用连续操作展示逐项增加、修正、撤回，而不只是最终截图。
- [ ] 五层组成图从一层长到五层，旧层不消失；对比关系无因果误导；汇聚保持来源身份。
- [ ] C08 概数不变成伪精确统计；C13 超容量未丢观点/关系；小画布和 reduced-motion 可阅读。
- [ ] 运行与本改动相关的检查，并完成 `npm run check`、`npm test`；报告真实执行结果与仍未验证项。

对应验收场景：C04—C08、C12、C13。

## 本项不包含

不做复杂数据可视化、任意场景生成、全屏炫技转场或在线插画生成。
