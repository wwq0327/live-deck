# [P2][后续][S12] 增加图片标注、素材复用与异步配图隔离

总任务：[持续理解与动态图示 #21](https://github.com/wwq0327/live-deck/issues/21)。文档版本：[开发交接](https://github.com/wwq0327/live-deck/blob/ea3a8c398acb97f3c8963e64094d6507d63e3066/docs/plans/2026-11-07-continuous-visual-thinking/HANDOFF.md)。

状态：待开发。所属方案：持续理解与动态思维可视化 v1。

## 目标

用合适图片辅助关系解释，接近参考视频同图逐步标注的效果，同时保证快路径不被素材等待阻塞。

## 前置任务

[S10 #31](https://github.com/wwq0327/live-deck/issues/31)

## 开发入口

素材接口、缓存/来源记录、renderer 图片与标注层、受控延迟测试。

先读 [开发交接](https://github.com/wwq0327/live-deck/blob/ea3a8c398acb97f3c8963e64094d6507d63e3066/docs/plans/2026-11-07-continuous-visual-thinking/HANDOFF.md)、[协议](https://github.com/wwq0327/live-deck/blob/ea3a8c398acb97f3c8963e64094d6507d63e3066/docs/plans/2026-11-07-continuous-visual-thinking/protocol.md)、[架构](https://github.com/wwq0327/live-deck/blob/ea3a8c398acb97f3c8963e64094d6507d63e3066/docs/plans/2026-11-07-continuous-visual-thinking/architecture.md) 与 [验收](https://github.com/wwq0327/live-deck/blob/ea3a8c398acb97f3c8963e64094d6507d63e3066/docs/plans/2026-11-07-continuous-visual-thinking/acceptance.md)。

## 工作范围

- 先用项目自有或许可清晰的本地素材，实现图片主体保留、标签增量、局部突出和压暗。
- 素材请求绑定 epoch/scene_id/语义版本，回到不匹配场景的结果丢弃或缓存，不覆盖当前图。
- 文字和逻辑关系仍由独立可修改图层承载，图片只辅助说明；没有图也能正常显示简单关系图。
- 在线检索/生成作为可选后续适配，接入前说明来源、成本与延迟，付费调用由用户显式启用。

## 验收

- [ ] 同一插画逐项增加标注，其他对象不重建；焦点变化用于解释，不改变讲者主张。
- [ ] C16 延迟素材、主题切换、失败和恢复均正确；主链路不等待图片。
- [ ] 保存素材来源/许可或生成方式记录；不直接使用研究视频截图作为产品资产。
- [ ] 运行与本改动相关的检查，并完成 `npm run check`、`npm test`；报告真实执行结果与仍未验证项。

对应验收场景：C12、C16，并回归 C09。

## 本项不包含

不把在线生成图片设为第一阶段依赖，不修改人物视频剪辑，不接入未经授权的付费或版权不明素材。

## 交付

一个聚焦 PR，链接本 Issue，说明输入输出、行为变化、验证证据和剩余限制。依赖未完成或验收缺失时保留 Issue 打开。模型无 Key 降级、接口连通与 mock 不能作为真实语义验收。
