# [P1][S09] 增加保持恢复、有限历史修正与独立人工纠正通道

状态：待开发。所属方案：持续理解与动态思维可视化 v1。

## 目标

让讲者可以连续讲述、回头澄清并控制画面；系统错误能被纠正，不强迫讲者等它逐页播放。

## 前置任务

S08

## 开发入口

语义模式的 Presenter/control、有限历史 UI 与状态/浏览器测试。

先读 [开发交接](../HANDOFF.md)、[协议](../protocol.md)、[架构](../architecture.md) 与 [验收](../acceptance.md)。

## 工作范围

- 保持只冻结可见快照，后台听取与理解继续；恢复直接 diff 到最新有效状态，不补播所有积压动画。
- 保留当前及最近4个归档场景，支持明确回指修正；修改归档不自动跳离当前画面。
- 提供选择对象后更正文字/关系或撤回的轻量控件，不做完整富文本编辑器；人工更正递增 graph_version。
- 控制操作使用独立事件通道，普通讲话中提到“清空/暂停”等词不自动触发控制。
- 范围外/模糊回指保留未决提示，不猜目标；reset 清理请求、账本、图和视图，迟到结果无效。

## 验收

- [ ] C14 保持期间继续输入并修正，恢复只出现最新有效图，已有对象仍稳定。
- [ ] 人工修正发生在模型在途期间，旧模型结果不得覆盖该修正；后续重新理解能接续。
- [ ] 上一场景更正可以回看核实，当前场景不受误写；键盘可操作且 reduced-motion 不改变语义。

对应验收场景：C03、C09、C14。

## 本项不包含
