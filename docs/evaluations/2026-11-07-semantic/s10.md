# S10 验收报告（2026-11-07）

结论：**未通过**。语义质量（关系 precision/recall、核心覆盖、严重失真）在确定性回放与 40 次真实 Flash 调用中达标；但语义上屏延迟比目标慢约 3 倍，长语音会话中 84% 的响应因转写修订被拒，单场景超容量时画面可读性不足。真实人口播、5—10 分钟长会、人工视觉签字与录屏仍未完成，S10 与总任务保持打开。

## 环境与口径

- 机器：macOS，Chrome 156（bsk 会话 `wclv`），1600×900 与 1280×720。
- ASR：本机 `asr.mjs`（sensevoice-int8，16 kHz 单声道）。
- 模型：`deepseek-flash`，`thinking: disabled`，`response_format: json_object`，`temperature 0.2`，`max_tokens` 默认 1400（截断时一次重试，上限 2400）。
- 调度：单在途、debounce 300 ms、maxWait 800 ms、客户端超时 13 s、服务端超时 12 s、每请求最多 3 条未消费 final。
- 样本：质量评测 8 个场景 × 5 次 = 40 次真实调用；语音评测两段 TTS（81.8 s / 62.7 s），非真人。所有失败样本保留，未剔除。

## 未完成 / 风险

- 没有真人 60—90 秒口播与 5—10 分钟长会；TTS 不能替代。
- 没有人工视觉验收签字与录屏；C12/C13 只有脚本断言与截图。
- 延迟未达标：需要更稳定的 partial 提交策略（例如按句/按 final 触发、或在版本冲突时复用可存活证据并只重算受影响部分），这不是参数微调能解决。
- 单场景超容量时布局不可读，需要续接场景的呈现与导航。
- 未在 CI 调用付费 API；`npm run eval:semantic` 需手动执行。
