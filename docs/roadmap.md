# 路线图

## 现在做到哪了

一个能用的最小闭环：本地转写 → 模型当场决策 → 模板渲染，边说边出页，端到端 1–1.5 秒。

验证过的场景：本机麦克风、拖拽 wav 回放、打字输入、40 秒演示稿。没有验证过：多人对谈、嘈杂会议室、英文、超过 30 分钟的连续使用。

## 已知限制

| 限制 | 影响 | 优先级 |
| --- | --- | --- |
| 能量 VAD 不是模型 | 吵的时候切碎或一直不收句 | 高 |
| 同音错字 | "一份"→"一粉"，"PPT"→"TTT" | 高 |
| 没有回退 | 说错了不会撤回上一页 | 中 |
| 底色节奏写死 | 每四页一张米白，不看内容 | 中 |
| 没有持久化 | 刷新页面就没了，讲完无法导出 | 中 |
| 只有一套视觉风格 | 不能换品牌色/字体 | 中 |
| 中文优先 | 英文能跑但断句和排版没调 | 低 |
| 没有图表 | 只有数字、没有柱状/折线 | 低 |

## 下一步（按性价比排）

### 1. 换 Silero VAD

现在用 `rms > max(0.012, noise×2.8)` 判断说话。换成 Silero VAD（onnx，约 1–2MB，CPU 实时）之后：

- 收句延迟可以从 420ms 压到 200ms 左右（模型比能量阈值更敢下判断）。
- 噪声环境不再需要手动调阈值。
- 顺便能拿到"这句话是不是说完了"的概率，替代现在的固定阈值。

影响面：只改 `stage.js` 的 VAD 部分 + `asr_worker.py` 里加一个 VAD 入口（或者全放前端，用 onnxruntime-web）。

### 2. 热词 / 词表

SenseVoice 的 sherpa-onnx 接口不支持 hotwords，但有两个变通：

- 转写后做一层模糊纠错（编辑距离 + 领域词表），把"一粉"改成"一份"。
- 用 whisper 的 `initial_prompt` 给词表（注意不能有全角标点，见排障文档）。

两件都做：默认走模糊纠错，用户可以切换到 whisper。

### 3. 回退 / 撤销

说错了要能撤。设计：保留最近 10 页的 `state.history`，说"回到上一页"或者按 `z` 就退回。语音指令的识别可以复用导演（让它输出 `action: "back"`）。

### 4. 页面导出

讲完想留下东西。两条路：

- **静态导出**：把 `state.history` 里的 JSON 渲染成一串静态 HTML（现在的模板直接复用），`?export=1` 下载 zip。
- **视频导出**：无头浏览器逐帧截图 + ffmpeg 合成。这个交给慢车道。

### 5. 主题系统

把 `stage.css` 里的 `--bg` `--ink` `--accent` `--pad` 抽成主题 JSON，支持：

- 品牌色（公司红/蓝）
- 浅色主题（会议室投影用）
- 字体选择（现在锁死系统黑体）

### 6. 慢车道：真正的富媒体

快车道的模板永远只有文字和色块。想要真图表、真图片，得让 agent 在后台生成 HTML 页面（hyperframes / 手写 DOM），塞进队列，在每个自然停顿点插入。

接口已经预留了：`POST /api/queue` + 前端每次 `show()` 前看一眼队列。

### 7. 多人 / 长会

现在的假设是"一个人在讲，句子之间有明显停顿"。多人对讲、连续 30 分钟不换气，需要：

- 说话人分离（谁在讲）
- 长时间不发散（transcript 越滚越长，得滚动窗口 + 定期摘要）

## 发布前待办

如果要把这个做成独立开源项目：

- [x] **定许可证**：MIT，见仓库根目录的 `LICENSE`。
- [ ] **CI**：`npm run check`（只做语法检查）+ 一个 headless 截图回归（现在 `docs/img/*.png` 就是基准图）。
- [ ] **模型分发**：SenseVoice 的 onnx 有 239MB，不能进仓库。写清楚从哪下、放哪个目录，最好加一个 `npm run fetch-model` 脚本。
- [ ] **英文 README**：现在只有中文。至少把开头那段翻过去。
- [ ] **一段 60 秒的 demo 视频**：比十张截图有说服力。
- [ ] **`sample.wav` 换成有版权的素材**：现在是用系统 TTS 生成的，没有版权问题，但听起来很机械。

## 不做的事

- **不做通用 PPT 生成器**。它的价值是"实时"，一旦允许"先想 10 秒再出 20 页"，就变成另一个产品了。
- **不做云端语音**。音频不出本机是这个项目成立的前提之一。
- **不做富文本编辑器**。想改字就让讲者重说一遍，或者以后做语音指令编辑。
